# 📚 하곰이(Hagom) 프로젝트 문서 모음 (docs/)

이 폴더는 팀원, 교수님, 그리고 협업하는 AI 에이전트가 읽을 수 있도록 **프로젝트의 모든 기획서, 보고서, 작업 지침서를 한곳에 모아둔 문서 보관소**입니다.

---

## 📂 문서 목록 및 역할 안내

| 파일명 | 형식 | 주요 내용 및 목적 |
| :--- | :---: | :--- |
| **`PRD_기획명세서`** | `.md` / `.docx` | **앱의 모든 기능과 화면별 공식 사양서**<br>- 5대 탭 상세 인터랙션, 모달 원칙, 달력 3단계 시각화 알고리즘, TDM 복약 시간 전환, 알림 매트릭스 수록 |
| **`AI_활용_개발_프로세스_보고서`** | `.md` / `.docx` | **과제 제출용 공식 보고서**<br>- 1단계(아이디어)부터 4단계(코드 구현 및 안티-슬롭 정제)까지 AI 도구와의 실전 협업 과정 기술 |
| **`보고서_기획서_보건약학적_배경`** | `.md` / `.docx` | **임상 및 보건약학적 배경 이론**<br>- ADHD/우울증 환자의 복약 순응도, TDM(치료약물모니터링) 혈중농도 유지 필요성, 비처벌적 UX의 의학적 근거 |
| **`AGENTS.md`** | `.md` | **팀원 및 AI 에이전트 개발 인수인계 지침서**<br>- 프로젝트 핵심 철학, 5대 디자인 헌법, 색상표의 임상적 의미, 버전 표기 공식(`v0.19.72`), 코드 구조 가이드 |
| **`PROGRESS.md`** | `.md` | **작업 진행 현황 기록부**<br>- 완료된 개발 내역 및 누적 마일스톤 로그 |
| **`README.md`** | `.md` | **저장소 메인 소개서**<br>- 핵심 가치, 화면별 기능 요약, 실행 명령어 가이드 |

> 💡 **Tip for Teammates**: 새로 개발에 합류하는 팀원이나 AI는 **`AGENTS.md`**를 가장 먼저 읽으면 프로젝트의 모든 규칙과 맥락을 한눈에 파악할 수 있습니다!
