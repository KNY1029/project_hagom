# 한국어 존댓말 & 헬스케어 톤 교정 스킬 (Korean Honorific & Healthcare Tone)

환자 대상 복약 및 디지털 헬스케어 앱에서 텍스트의 반말(해체)이나 어색한 번역투 경어를 **따뜻하고 신뢰감 있는 '해요체 존댓말'**로 변환하고 검수하는 규칙입니다.

---

## 1. 핵심 원칙: "해요체" 단일 표준 (Toss-style Polite & Warm)

1. **하십시오체(~습니다) 배제**: 군대식의 딱딱하고 거리감을 주는 어체 대신, 일상에서 다정하게 건네는 **‘해요체(~해요, ~어요)’**를 기본값으로 통일합니다.
2. **반말(~어/아, ~지, ~자) 전면 금지**: 환자에게 무례하거나 가볍게 느껴질 수 있는 반말을 배제하고, 존중받는 느낌을 줍니다.
3. **겸양어 및 주체 정돈**:
   - `너만의 속도` ➔ `나만의 속도` 또는 `회원님의 속도`
   - `네가 참 대견해` ➔ `스스로가 참 대견해요`
   - `약 챙겨라 (지시형)` ➔ `약 챙기기를 응원해요 (지지형)`

---

## 2. 반말 ➔ 존댓말 변환 매핑 사전

| 반말 (Casual / Hae-che) | 정중하고 따뜻한 존댓말 (Haeyo-che) | 교정 의도 |
| :--- | :--- | :--- |
| **~했어 / ~했지?** | **~했어요 / ~하셨나요?** | 부드러운 의문형 및 보고형 어미 |
| **~해 / ~해봐** | **~해보세요 / ~하면 좋아요** | 강요가 아닌 권유형 |
| **~고마워** | **~고마워요 / 감사해요** | 온기 있는 감사 표현 |
| **~괜찮아** | **~괜찮아요 / 다 잘하고 계세요** | 비처벌적 지지 |
| **~충분해** | **~충분해요** | 환자의 불안 완화 |
| **너 / 네가** | **스스로 / 나 / 회원님** | 2인칭 지칭어의 존중화 |
| **~가자 / ~하자** | **~가요 / ~함께해요** | 청유형의 존칭화 |
| **~지켜본다** | **~기다리고 있어요** | 감시나 압박 대신 다정한 대기 표현 |

---

## 3. 검수 체크리스트 (Linting Rules)

- [ ] 문장 끝이 `~다`, `~어`, `~지`, `~자` 등 반말 종결어미로 끝나지 않았는가?
- [ ] 2인칭 대명사 `너`, `네가`, `너의`가 텍스트에 포함되어 있지 않은가?
- [ ] 지나친 사물 존칭(`약이 기다리십니다`)이나 AI 번역투가 섞여 있지 않은가?
- [ ] 문장 전체가 일관된 `~해요/어요` 어조를 유지하고 있는가?
