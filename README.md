# 🐻 하곰이 (Hagom) - 복약 & 작은 습관 케어 모바일 앱

> **보건약학프로젝트 (Health & Pharmacy Course Project)**  
> 정신건강(ADHD, 우울증 등) 타겟 환자의 복약 순응도 향상과 일상 자가 모니터링을 돕는 **비처벌적(Non-punitive) 심리 케어 모바일 앱**입니다.

---

## 🌟 핵심 가치와 비처벌적 UX 철학 (Non-punitive Doctrine)

1. **❌ 스트릭(Streak) 질책 및 채찍질 배제**:
   - 연속 기록 실패에 대한 경고나 실망감을 절대 주지 않으며, 듀오링고식 압박을 배제합니다.
2. **⭕ 누적 달성 지표 칭찬 (Self-Monitoring)**:
   - *"이번 달에 벌써 15번이나 약을 챙겨 드셨어요!"*와 같이 쌓여가는 작은 노력 그 자체를 축하합니다.
3. **⭕ 접속 자체의 효능 인정**:
   - 약이나 습관을 다 하지 못했더라도, 앱에 접속해 얼굴을 비춘 것만으로도 마스코트 **'하곰이'**가 반갑게 맞이하며 칭찬합니다.
4. **⭕ 과거 날짜 사후 기록 무조건 축하 (소급 축하 시스템)**:
   - 어제나 과거의 복약을 뒤늦게 완료로 수정해도 눈치를 주지 않고, *"언제든 기록해 준 것 자체가 멋져요! ✨"*라며 똑같이 따뜻하게 축하합니다.

## 📱 주요 구현 기능 (Stage 0 ~ Stage 2)

### 1. 💊 복약 관리 (Medication Management)
- **2단계 마법사 모달**:
  - 1단계: 약 이름, 용량 및 복용법, 의사 처방 여부
  - 2단계: 복용 주기(매일/오늘만/N일마다/필요 시), 시간대 칩(아침/점심/저녁/취침 전/커스텀 기타), 복용 기간
- **원탭 복약 완료 & 회차 슬롯**:
  - 카드 내 회차별 슬롯 칩(`아침 8:00`, `점심 12:30`) 및 우측 완전 고정 `[지금 복용]` 버튼.
  - 완료된 회차 슬롯 탭 시 실제 복용 시간 수정(`오후 12:45`) 및 해당 회차 핀셋 취소 지원.
- **회차별 스마트 건너뛰기**:
  - 카드 아코디언 메뉴에서 남은 특정 회차만 핀셋 건너뜀 지원.
  - 건너뛴 회차는 취소선과 흐린 텍스트로 자연스럽게 처리되어 시각적 부담을 줄임.
- **안전한 수정 & 삭제**:
  - 모달 내 눈에 띄는 대칭형 삭제 버튼 (`AppColors.neutralDark`) 및 1초 되돌리기(롤백).

### 2. 🌱 작은 습관 관리 (Micro-Habits Care)
- **비처벌적 3단계 평가 시스템**:
  - `○ 대기` ➔ `◐ 조금 실천 (0.5점)` ➔ `● 완료 (1.0점)`.
  - 조금이라도 시도한 것 자체를 가치 있게 인정하는 분수 표기 달성 게이지 바 (`2½ / 4개 완료 · 63%`).
- **유연한 습관 설정 모달**:
  - 7개 요일 다중 선택 칩, 하루 다회 실천(`targetPerDay`), 복수 알림 시간 지원.

### 3. 📅 기록 달력 & 할일 (Calendar & Tasks - 신규 6안 규격)
- **6안 날짜 셀 컬러링 알고리즘**:
  - **100% 완료일**: 날짜 셀 전체를 **'통으로' 연초록 파스텔 틴트(`#E6F8F0`)**로 채움 + 짙은 초록 숫자(`#065F46`).
  - **부분 달성일**: 하단 오렌지 캡슐 바(`#F59E0B`).
  - **0% 미복용일**: 비처벌적 안심 소프트 슬레이트 그레이 바(`#D1D5DB`).
  - **오늘 날짜**: 보라색 테두리(`#7B61A8`).
  - **미래 날짜**: 진행도 일체 미표시 (깨끗한 초기화).
- **PRD 공식 라벤더 닷 모서리 핀**:
  - 일정이 등록된 날짜 셀 우측 상단 모서리(`top: 4, right: 4`)에 라벤더 닷(`• #7B61A8`) 단독 배치.
- **하단 데일리 아코디언 패널**:
  - **그날의 할일**: 최상단 우선 배치, 체크박스 완료 토글 및 `+ 할일 추가` 모달.
  - **복약 현황**: 1줄 요약 바 + `[자세히 보기 ▼]` 서랍식 아코디언.
  - 약별 / 회차별 개별 슬롯 확인 및 핀셋 소급 완료 수정.
  - 과거 날짜 사후 수정 시 하곰이의 다정한 소급 축하 토스트 즉시 발동.

### 4. 🐻 마스코트 하곰이 상호작용 (Companion Interaction)
- **축하 토스트 (`CelebrationToast`)**:
  - 복약/습관 체크 시 하단에 하곰이 얼굴과 함께 다양하고 따뜻한 랜덤 칭찬 멘트 출력 (지시/압박성 문구 배제).
- **상단 헤더 상시 아바타**:
  - 터치 즉시 반응하는 1줄 와이드 말풍선(340dp)을 통해 16가지 무조건적인 위로 멘트 랜덤 출력.
- **하곰이의 방 (`CompanionRoomScreen`)**:
  - 터치할 때마다 따뜻한 대사를 건네며, 실제 누적 발걸음("부드럽게 시도한 횟수", "다시 돌아온 횟수") 통계 연동.

## 📂 프로젝트 구조

```
project_hagom/
├── app/                          # Flutter 모바일 앱 소스코드
│   ├── lib/
│   │   ├── constants/            # 테마 색상(AppColors), 에셋(AppAssets), 대사(HagomDialogue)
│   │   ├── models/               # 복약(MedicationItem), 습관(HabitItem), 일정(TaskItem)
│   │   ├── screens/              # 메인 네비게이션, 복약, 습관, 달력, 하곰이의 방, 설정
│   │   ├── state/                # 싱글톤 상태 관리자 (AppStateManager)
│   │   └── widgets/              # 하곰이 축하 토스트(CelebrationToast) 등
│   └── pubspec.yaml
├── PRD_기획명세서.md              # 요구사항 기술 명세서
├── AGENTS.md                     # AI 개발 작업 지침 및 비처벌적 UX 헌법
├── PROGRESS.md                   # 단계별 개발 진행 기록
├── 보고서_기획서_보건약학적_배경.md # 임상 및 약학적 배경 보고서
└── assets/                       # 공식 일러스트 원본 에셋 (hagomi.png)
```
