# 🐻 하곰이 (Hagom) - 복약 & 일상 루틴 케어 모바일 앱

> **보건약학프로젝트 (Health & Pharmacy Course Project)**  
> 정신건강(ADHD, 우울증 등) 타깃 환자의 복약 순응도를 높이고 일상 자가 모니터링을 돕는 **비처벌적(Non-punitive) 심리 케어 모바일 앱**입니다.

---

## 🌟 핵심 가치와 비처벌적 UX 철학

1. **연속 기록(Streak) 실패 질책 금지**:
   - 연속 기록이 끊겨도 경고나 실망감을 주지 않고, **월간 누적 성공 일수**를 중심으로 칭찬합니다.
2. **과거 날짜 사후 기록 무조건 축하 (소급 축하 정책)**:
   - 지난 날짜의 약이나 습관을 뒤늦게 체크해도 똑같이 반갑고 다정하게 축하합니다.
3. **접속 자체의 가치 인정 (Self-Monitoring)**:
   - 약이나 습관을 다 하지 못했더라도, 앱을 켠 것만으로도 마스코트 **'하곰이'**가 따뜻하게 맞아줍니다.
4. **체크마크(✓) 배제 & 색상 중심 피드백**:
   - 버튼 크기 흔들림을 막고 안정감을 주기 위해 체크 아이콘 없이 **단정한 파스텔 색상 변화**로 완료를 전달합니다.

## 📱 주요 화면 및 기능

### 1. 💊 복약 탭 (Meds)
* **2단계 추가/수정 모달**: 약 정보, 복용 주기(`매일` / `특정 요일` / `며칠 간격` / `시간 간격` / `오늘만` / `필요 시`), 복약 시점 설정.
* **시간 간격 복약**: 첫 복용 시각만 설정하면 복용 버튼을 누를 때마다 다음 복약 시간이 실시간 자동 계산.
* **오늘은 아닌 약 하단 1줄 슬림화**: 주 1회 복용약 등 오늘은 복용일이 아닌 약은 상단을 어지럽히지 않고 하단에 얇은 1줄로 조용하게 분리.
* **TDM 시간 동적 전환**: 완료 전 예정 시각(`아침 8:00`) ➔ 완료 후 실제 복용 시각(`아침 8:05`)으로 실시간 전환.

### 2. 🌱 작은 습관 탭 (Habits)
* **3단계 평가 순환**: `대기` ➔ `조금 실천 (0.5점)` ➔ `완료 (1.0점)`.
* **정밀 게이지**: 하루 4잔 중 1잔(`0.25점`)도 정확한 수치로 반영되는 비처벌적 달성률 바.
* **주간 습관 완료 시 휴식 보장**: 주 1회 목표를 이미 달성한 습관은 하단 1줄로 내려가 오늘의 휴식을 보장.

### 3. 📅 달력 & 할일 탭 (Calendar & Tasks)
* **초간단 3단계 시각화 알고리즘**:
  - 🟢 **전부 다 한 날 (복약 100% + 습관 100%)**: 통 연초록 파스텔 틴트 (`#E6F8F0`), 하단 바 없음. (일요일 빨간 숫자 보존)
  - 🚨 **처방약 누락일**: 흰색 셀 + 선명한 빨간색 캡슐 바 (`#EF4444`).
  - 🟤 **뭔가 덜 한 날**: 흰색 셀 + 차분한 웜브라운 캡슐 바 (`#8B5E3C`).
  - ⚪ **미래 날짜**: 바 없이 완전한 순백색 초기화.
* **오늘 vs 과거 동작 분리**:
  - 오늘: 수정 버튼 없이 단순 1줄 요약만 노출 (각 탭에서 실천 유도).
  - 과거: `수정하기` 버튼 클릭 시 펼쳐지며, 복약 시각 질문(모름 선택지 포함) 및 습관 선택 팝업을 거쳐 안전하게 기록.
* **할일/한일 일정 관리**: 과거 날짜는 `한일 추가`로 자동 전환되며, `며칠 전` / `시간·분 전` 다중 알림 및 요일별 반복 완비.

### 4. 🐻 하곰이의 방 (Companion Room)
* 터치 시 흔들림 없는 **110dp 고정 높이 말풍선**에서 이모티콘 찌꺼기 없는 다정하고 깊이 있는 위로 텍스트 출력.
* 누적 발걸음("부드럽게 시도한 횟수", "다시 돌아온 횟수") 통계 연동.

### 5. ⚙️ 설정 탭 (Settings)
* **5대 알림 매트릭스**: 알림 빈도 3단계(`최소` / `기본` / `적극적`), 처방약 상시 켜짐 스마트 토글, 기능별 자유 스위치.
* **의료진 상담용 엑셀(CSV) 다운로드**: 스마트폰 `Download` 폴더로 TDM 복약 차트 파일 즉시 저장.
* **로컬 DB 영구 저장**: `SharedPreferences` 연동으로 앱 재실행 후에도 모든 데이터 100% 보존.

## 🏷️ 버전 표기 규칙 (Semantic Iteration System)

> **`v{A}.{B}.{C}`** (현재: `v0.19.68`)
* **`A`**: 구글 플레이스토어 정식 배포 시에만 `1`로 승격 (현재 프로토타입은 `0`).
* **`B`**: Git 저장소 누적 커밋 횟수.
* **`C`**: 사용자와 실시간 피드백을 주고받으며 화면을 정밀 수정한 총 누적 횟수.
